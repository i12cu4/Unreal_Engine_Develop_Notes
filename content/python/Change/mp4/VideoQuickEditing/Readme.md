## 📋 使用指南

### ✅ 标准操作流程
1. **启动程序**  
   - 拖动**第一个视频**到程序图标上 → 自动打开终端
   
2. **添加后续视频（循环操作）**  
   - 将**下一个视频**拖入终端窗口 → **按回车确认**  
   - 终端显示：`✅ 已添加 (2): video2.mp4`  
   - 重复此步骤添加所有视频（顺序 = 拖入顺序）
   
3. **触发合并**  
   - 添加完成后，**直接按回车（空输入）**  
   - 程序自动校验数量 → 开始无损合并
   
4. **获取结果**  
   - 合并文件保存在**首个视频所在目录**  
   - 文件名示例：`2026-03-13-14-30-22.mp4`

### ⚠️ 关键注意事项
- **必须按回车确认**：每次拖入视频后需手动按回车（终端输入机制限制）
- **顺序即生命线**：合并顺序 = **用户添加顺序**（非文件名/时间戳排序）
- **最少2个视频**：仅1个视频时会提示"至少需要2个视频"
- **重复文件拦截**：相同路径视频自动跳过并提示
- **无损前提**：所有视频需编码参数一致（否则合并失败）

> 💡 **提示**：与裁剪工具共用同一FFmpeg路径配置（修改`merge_tool.py`第7行`FFMPEG_PATH`）

## ❓ 常见问题
**Q：为什么拖入视频后必须按回车？**  
A：Windows终端输入机制决定——拖入路径仅填充输入框，需回车触发程序读取（系统级限制，非程序缺陷）

**Q：如何调整合并顺序？**  
A：严格按**添加顺序**合并：先拖入的在前，后拖入的在后。如需调整，重新运行程序并按目标顺序添加
