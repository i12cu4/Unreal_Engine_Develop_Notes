# 压缩包密码检测工具（7-Zip版）

## 核心功能
- 静默扫描目录，精准识别 .rar/.zip/.7z 加密文件
- 智能区分真实密码保护与文件错误（损坏/路径错误等）
- 仅输出加密文件完整路径（每行一个，便于管道处理）
- 单文件检测超时30秒（防卡死）

## 配置
修改脚本首行路径（关键！）：  
SEVEN_ZIP_PATH = r"C:\Program File\7-Zip\7z.exe"  
⚠️ 注意：默认配置为 Program File（无s），请按实际安装路径修改

## 使用
命令行调用：  
python 压缩包密码检测工具.py "E:\交付目录"  
- ✅ 必须命令行调用（双击无输出，因隐藏控制台窗口）  
- ✅ 无加密文件时无任何输出  
- ✅ 仅Windows支持，需已安装7-Zip  

## 故障排查
| 问题     | 解决方案                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------- |
| 无输出   | 1. 确认目录含压缩包<br>2. 检查7-Zip路径（Program Files vs Program File）<br>3. 用测试加密包验证 |
| 误报     | 脚本已过滤：跳过"文件不存在"、"非压缩包"等错误                                                  |
| 运行报错 | 临时注释 hide_console_window() 查看错误详情                                                     |

## 联动建议
作为RAR工具集前置检查：  
1. 检测加密文件 → 人工复核或用 RAR解密-Decryption.py 解密  
2. 无加密后 → 执行 RAR检损 → RAR检二压 → 导出层级
