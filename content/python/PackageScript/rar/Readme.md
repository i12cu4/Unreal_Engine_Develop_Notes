## 🌳 脚本1：RAR导出层级-OutputFileDir.py（结构可视化）  
### 功能说明  
将RAR内部文件结构导出为树形文本，清晰展示层级关系：  
✅ 多编码智能解码（完美支持中文路径）  
✅ 自动生成同名.txt文件（覆盖旧文件）  
✅ 空压缩包智能标识 + 文件总数统计  
✅ 实时进度反馈  
🎯 适用：资源包结构审查、交付文档生成、教学演示  

### 配置说明  
| 配置项     | 说明                     | 示例                           |
| ---------- | ------------------------ | ------------------------------ |
| 目标目录   | RAR文件所在文件夹        | E:\Download                    |
| WinRAR路径 | Rar.exe路径（注意：无s） | C:\Program File\WinRAR\Rar.exe |

### 使用步骤  
1️⃣ 修改脚本路径配置  
2️⃣ 双击运行 → 生成同名.txt文件（Forest.rar → Forest.txt）  
3️⃣ 查看结果：  
   - 顶部显示压缩包名，底部统计文件总数  
   - 树形结构清晰展示文件夹/文件层级  
   - 中文路径完整无乱码  

⚠️ 注意：旧.txt文件会被覆盖（重要报告请提前备份）

## 🔒 脚本2：RAR加密-Encrypt.py（安全加固）  
### 功能说明  
为RAR添加密码保护，生成独立加密副本：  
✅ 原文件保留（新文件带"_encrypted"后缀）  
✅ 双重加密：文件名+内容加密（-hp参数）  
✅ 临时解压自动清理（无残留风险）  
✅ 详细日志记录（含DEBUG级调试信息）  
🎯 适用：敏感资源分发、客户交付加密、隐私保护  

### 配置说明  
| 配置项     | 说明                               | 示例                                    |
| ---------- | ---------------------------------- | --------------------------------------- |
| 目标目录   | 需加密RAR所在目录（递归子文件夹）  | C:\Users\chru\Desktop\UE-VRGK-v2-master |
| 密码       | **必须修改！**（默认1234极不安全） | 1234 → **请设强密码**                   |
| 输出后缀   | 加密文件标识                       | _encrypted                              |
| WinRAR路径 | WinRar.exe路径（注意：无s）        | C:\Program File\WinRAR\WinRar.exe       |

⚠️ **安全警告**：默认密码1234！使用前务必修改为强密码

## 📦 脚本6：RAR压缩-Package.py（智能打包）  
### 功能说明  
批量压缩文件夹，自动排除冗余项：  
✅ 拖放操作：直接拖拽文件夹到脚本上即可压缩  
✅ 智能排除：自动跳过.vs/.svn/Binaries等冗余目录  
✅ 文件名清理：自动处理特殊字符（括号/空格等）  
✅ 当前目录兜底：无拖放时压缩当前目录  
🎯 适用：资源打包交付、项目归档、日常备份  

### 配置说明  
| 配置项     | 说明                                | 示例                           |
| ---------- | ----------------------------------- | ------------------------------ |
| 排除列表   | 自动跳过的文件/文件夹（支持通配符） | .vs, Binaries, *.rar           |
| WinRAR路径 | Rar.exe路径（注意：无s）            | C:\Program File\WinRAR\Rar.exe |

### 使用步骤  
1️⃣ 修改EXCLUDE_LIST（按需增删排除项）  
2️⃣ **拖放文件夹到脚本上** → 自动压缩生成同名.rar  
3️⃣ 查看结果：  
   - 成功：显示"成功创建: XXX.rar"  
   - 失败：显示具体错误原因  

⚠️ 注意：压缩大文件夹需较长时间；确保磁盘空间充足

## 🔄 脚本7：RAR压中压.py（检测+移动）  
### 功能说明  
检测RAR内是否含其他压缩包，并可移动至指定目录：  
✅ 拖放操作：支持拖放文件/文件夹批量检测  
✅ 智能识别：精准检测.zip/.7z/.rar嵌套  
✅ 一键移动：检测到的文件可自动移至目标目录  
✅ 存在检测：目标目录同名文件自动跳过  
🎯 适用：资源库清理、嵌套压缩专项处理、自动化流水线  

### 配置说明  
| 配置项       | 说明                                 | 示例                           |
| ------------ | ------------------------------------ | ------------------------------ |
| WinRAR路径   | Rar.exe路径（注意：无s）             | C:\Program File\WinRAR\Rar.exe |
| 目标移动路径 | 检测到的文件移动位置（留空则不移动） | D:\NestedCompressedArchives    |

### 使用步骤  
1️⃣ 修改TARGET_MOVE_PATH（如需移动功能）  
2️⃣ **拖放RAR文件/文件夹到脚本上**  
3️⃣ 查看结果：  
   - 无嵌套：提示"未发现包含其他压缩文件的RAR文件"  
   - 有嵌套：列出路径 + 自动移动（若配置了目标路径）  

⚠️ 注意：移动前请确认目标路径有效；同名文件会跳过

## ⚠️ 通用关键提醒（必读！）  
| 问题                      | 解决方案                                                                       |
| ------------------------- | ------------------------------------------------------------------------------ |
| 所有脚本报"找不到rar.exe" | 脚本中路径为"Program File"（无s），请按实际安装路径修改（通常为Program Files） |
| 中文显示乱码              | 系统区域设置为中文（控制面板→区域→中文）                                       |
| 脚本2/3密码问题           | 加密脚本密码**必须修改**；解密脚本密码需与加密时完全一致                       |
| 拖放操作无效              | 确保直接拖放文件夹到.py文件上（非快捷方式）                                    |
| 首次使用                  | 务必用测试文件验证效果，确认无误再批量处理                                     |

## 💡 高效工作流组合  
✨ **资源包交付全流程**：  
1️⃣ 用【脚本6】压缩项目（自动排除冗余）  
2️⃣ 用【脚本5】检损 → 确保文件完整  
3️⃣ 用【脚本4/7】检二压 → 清理嵌套压缩包  
4️⃣ 用【脚本1】导出层级 → 生成结构文档随包交付  
5️⃣ 用【脚本2】加密 → 敏感资源安全分发  
6️⃣ 接收方用【脚本3】解密 → 获取无密资源  

✨ **安全守则**：  
✅ 脚本2密码**必须修改**（默认1234极不安全！）  
✅ 重要操作前备份原文件（10秒保平安）  
✅ 路径配置核心：所有脚本WinRAR路径均为"Program File"（无s），请按实际安装位置修改！
