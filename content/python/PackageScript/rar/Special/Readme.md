## 🌟 脚本1：图种.py（制作隐藏压缩包的图片）  
### 功能说明  
将PNG图片与RAR压缩包无缝合并，生成“图种”：  
✅ 看图软件打开：正常显示原图  
✅ 解压软件打开：可提取隐藏的RAR全部内容  
✅ 重命名.rar后缀：同样能解压验证  
🎯 适用：资源隐蔽分享、趣味玩法、防误删备份  

### 使用步骤  
1️⃣ 准备素材：  
   - 一张PNG格式封面图（如1.png）  
   - 一个需隐藏的RAR压缩包（如2.rar）  
2️⃣ 修改脚本配置（用记事本打开）：  
   - 源PNG路径 → 填写封面图完整路径  
   - 源RAR路径 → 填写压缩包完整路径  
   - 目标PNG路径 → 填写生成图种的保存路径  
3️⃣ 双击运行 → 生成新PNG文件（如3.png）  
4️⃣ 验证效果：  
   - 用看图软件打开3.png → 显示原图  
   - 用WinRAR打开3.png → 解压出2.rar内容  

⚠️ 注意：  
- 仅支持PNG作为封面（JPG合并易损坏）  
- 生成文件大小 = 原PNG大小 + RAR大小  
- 路径含中文/空格请确保路径正确（脚本已兼容）

## 🧹 脚本2：RAR检查文件存在-RarFileExistenceDetection.py（清理RAR冗余文件）  
### 功能说明  
智能扫描RAR内冗余项（编译缓存/广告文件等），安全清理并生成双报告：  
✅ 自定义删除清单（文件/文件夹名）  
✅ 安全替换机制（失败不损原文件）  
✅ 控制台实时反馈 + CSV详细记录  
✅ 进度条可视化处理过程  
🎯 适用：资源包交付前净化、批量优化、企业审计留痕  

### 配置说明  
| 配置项 | 说明 | 示例 |  
|--------|------|------|  
| WinRAR路径 | 主程序路径（注意：脚本中为无s设计） | C:\Program File\WinRAR\WinRAR.exe |  
| RAR命令行路径 | Rar.exe路径（注意：无s） | C:\Program File\WinRAR\Rar.exe |  
| 目标目录 | 待处理RAR所在文件夹 | G:\agw |  
| 删除模式 | 需清理的名称列表（含广告文件） | Saved, Intermediate, Build, 各类.url/.txt等 |  
| 报告类型 | console/csv/both | both（双报告） |  
| CSV保存目录 | 报告存储位置 | 同目标目录 |  

### 使用步骤  
1️⃣ 用记事本打开脚本 → 修改【用户配置区域】  
2️⃣ 双击运行 → 自动扫描并清理匹配项  
3️⃣ 查看结果：  
   - 控制台：实时显示[成功]/[跳过]/[失败]状态  
   - CSV报告：含删除明细（路径/文件/错误信息）  

⚠️ 注意：  
- 脚本路径为"Program File"（无s），请按实际安装位置修改  
- 首次使用建议先备份重要RAR  
- CSV用Excel打开需选"UTF-8"编码（推荐WPS直接打开）

## 🖼️ 脚本3：RAR解压图片-RarUnzipsPicture.py（批量提取封面图）  
### 功能说明  
自动解压RAR内图片到同目录，智能防重复：  
✅ 优先提取根目录图片，其次子目录  
✅ 同名图片已存在则自动跳过  
✅ 进度条实时显示处理状态  
✅ 临时文件自动清理  
🎯 适用：素材库封面生成、批量预览、资源归档  

### 配置说明  
| 配置项 | 说明 | 示例 |  
|--------|------|------|  
| 目标路径 | 存放RAR的文件夹 | C:\Users\chru\Desktop\Task |  
| WinRAR路径 | Rar.exe路径（注意：无s） | C:\Program File\WinRAR\Rar.exe |  

### 使用步骤  
1️⃣ 将待处理RAR放入目标文件夹  
2️⃣ 修改脚本中的路径配置  
3️⃣ 双击运行 → 生成与RAR同名的.png/.jpg文件  
4️⃣ 查看结果：  
   - 成功：目录出现新图片  
   - 跳过：控制台提示"已存在同名图片"  
   - 失败：显示具体错误原因  

⚠️ 注意：  
- 仅提取第一个匹配的图片（.png/.jpg）  
- 路径含中文需系统区域设为中文  
- 临时目录自动清理，无需手动操作

## 🏷️ 脚本4：RAR前缀-RarReanme(覆盖).py（智能重命名RAR）  
### 功能说明  
分析RAR内部结构，提取核心内容名作为前缀重命名：  
✅ 智能跳过Content/库文件等通用目录  
✅ 自动清理原文件名中已有[]前缀（防重复）  
✅ 提取名自动去除空格（Forest Scene → ForestScene）  
✅ 文件存在时自动跳过（防覆盖）  
🎯 适用：资源包规范化命名、素材库批量整理  

### 配置说明  
| 配置项 | 说明 | 示例 |  
|--------|------|------|  
| 处理目录 | RAR所在根目录（递归子文件夹） | F:\UE资源整合包 |  
| 跳过文件夹 | 遇到这些名则深入下一层查找 | Content, 库文件, data, config |  

### 使用步骤  
1️⃣ 安装依赖库：命令提示符执行 `pip install rarfile`  
2️⃣ 修改脚本底部目录路径  
3️⃣ 双击运行 → RAR自动重命名为 [提取名]原文件名.rar  
4️⃣ 查看结果：  
   - 成功：显示重命名路径  
   - 跳过：提示"多卷压缩包"/"需密码"/"未提取到名称"  

⚠️ 注意：  
- **必须提前安装rarfile库**（否则报错）  
- 仅处理.rar后缀文件（其他格式自动忽略）  
- 提取逻辑：移除原文件名开头[]内容 → 添加新前缀

## ⚠️ 通用关键提醒  
| 问题 | 解决方案 |  
|------|----------|  
| 所有脚本报"找不到rar.exe" | 脚本中路径为"Program File"（无s），请按实际安装路径修改（通常带s） |  
| 脚本4报"ModuleNotFoundError" | 命令提示符执行：pip install rarfile |  
| 中文路径乱码/失败 | 系统区域设置为中文（控制面板→区域→中文） |  
| 处理中断 | 已完成项保留；脚本2/3有进度条可续操作 |  
| 首次使用 | 务必用测试文件验证效果，确认无误再批量处理 |
