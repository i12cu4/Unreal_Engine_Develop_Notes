## 🚀 二、通用三步上手（所有脚本通用）  
### 1️⃣ 安装依赖（10秒）  
✅ 安装 WinRAR（免费版即可）  
✅ 默认安装路径：C:\Program File\WinRAR\（注意：程序中是没有s的） 倘若你要自定义路径，请改这一行的路径  

### 2️⃣ 配置脚本（15秒）  
📝 用记事本打开任一脚本 → 修改顶部【用户配置区域】：  
🔹 目标文件夹路径：  
   HybridMode/RarFastMode: target_dir = r"你的文件夹路径"  
   WinRarMode: TARGET_DIR = r"你的文件夹路径"（注意变量名大小写）  
🔹 清理目标列表：  
   delete_patterns = ["Saved", "Intermediate", "Build", ...] （按需增删）  
🔹 ⚠️ WinRAR路径说明：  
   脚本中已预设为 C:\Program File\WinRAR\（无s）  
   若你的实际安装路径不同（如 C:\Program Files\WinRAR\），请直接修改该配置行  

❗ WinRarMode.py 特别注意：  
→ 配置区变量名必须为 delete_patterns（全小写！）  
→ 若报错 NameError: name 'DELETE_PATTERNS' is not defined，请将脚本内所有 DELETE_PATTERNS 替换为 delete_patterns  

### 3️⃣ 运行（5秒）  
✨ 双击脚本 → 自动处理 → 查看终端结果  
✨ 按 Ctrl+C 可安全中断  
✨ 无需安装额外库（tqdm 缺失时自动降级）

## 🎯 四、选择指南（文字版）  
👉 选【⚡ RAR删除-WinRarMode.py】当：  
🔹 不需要任何报告  
🔹 追求极致处理速度  
🔹 压缩包结构简单（扁平化）  
🔹 个人日常快速清理（"删完即走"）  

👉 选【📊 RAR删除-RarFastMode.py】当：  
🔹 需要生成清理报告备查  
🔹 压缩包为英文路径或无特殊字符  
🔹 遇到过"错误码10"问题  
🔹 需要批量处理后复盘  

👉 选【🌐 RAR删除-HybridMode.py】当：  
🔹 压缩包含中文/特殊字符路径  
🔹 需要交付给客户或团队  
🔹 企业级审计留痕需求  
🔹 对报告编码兼容性要求高（Excel直开无乱码）

## ⚠️ 五、关键注意事项  
| 问题                      | 解决方案                                                              |
| ------------------------- | --------------------------------------------------------------------- |
| 🔴 路径报错"找不到rar.exe" | ✅ 脚本中配置为 Program File（无 s），请根据你的实际安装路径修改配置行 |
| 🔴 WinRarMode.py变量名报错 | ✅ 配置区必须用 delete_patterns（小写）；脚本内大写请统一替换          |
| 🔴 中文文件名乱码          | ✅ 优先用 HybridMode.py；其他脚本需系统区域设为中文                    |
| 🔴 "错误码10"反复出现      | ✅ 三脚本均已内置防护（智能过滤父子路径）                              |
| 🔴 CSV报告Excel打开乱码    | ✅ HybridMode.py生成的CSV可直开；其他需Excel导入时选"65001: Unicode"   |
| 🔵 处理后文件变大          | ℹ️ 属正常现象（重压参数差异），HybridMode.py使用 -m5 高压缩率          |

## 💡 六、实用技巧  
✨ 配置复用：将 delete_patterns 保存为独立文本文件，三脚本共用  
✨ 组合工作流：  
   - 先用 📊 RarFastMode.py 处理少量样本（生成报告验证效果）  
   - 确认无误后，用 ⚡ WinRarMode.py 批量处理剩余文件（提速50%+）  
✨ 备份习惯（PowerShell）：  
   robocopy "源路径" "备份路径" *.rar /S

## 🌈 七、安心提示  
✅ 所有脚本均不删除原压缩包（HybridMode生成新包替换，其他直接修改原包）  
✅ 重要数据处理前务必备份（10秒保平安！）  
✅ 首次使用建议先用 🌐 HybridMode.py 处理1个样本包验证效果  
✅ 路径配置核心：脚本中写的是 Program File（无s），请按你的实际安装位置修改！
